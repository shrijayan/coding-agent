# Coding Agent

A tiny AI coding assistant you run in your terminal. You describe what you
want in plain English, and it actually reads your files, writes code, fixes
bugs, and runs commands to get it done - it doesn't just describe what to
do, it does it.

Think of it like hiring a junior developer who sits at your keyboard: you
give them a task in plain English, they open the right files, make the
change, run it to check it works, and tell you what they did.

This guide assumes no prior experience with any of these tools. Follow the
numbered steps in order and you'll have it running.

## 1. See it in action

Here's a real example of what a session looks like. `you>` is what a
person typed; everything else is the agent working and answering:

```
Coding Agent ready. Type 'exit' to quit.

you> Create a file called hello.py that prints "Hello World", then run it
  [tool] write_file({'path': 'hello.py', 'content': 'print("Hello World")\n'})
  [tool] bash({'command': 'python3 hello.py'})

agent> Created `hello.py` and ran it — output: `Hello World`.

you> exit
Bye.
```

This is a real, unedited run of the exact prompt above. The `[tool] ...`
lines are the agent showing its work - it's telling you exactly which file
it touched or which command it ran, so nothing happens behind your back.
The wording of the final `agent>` answer is generated by the AI, so it
will be phrased a little differently each time you run it - that's
expected, not a bug.

## 2. What it can and can't do

**It can, today:**
- Read a file
- Create a new file, or overwrite an existing one
- Edit one exact part of a file (a precise find-and-replace, not a guess)
- Run terminal/shell commands (e.g. run a script, run tests, install a package)
- List the files and folders in a project

**It cannot do (yet) - good to know before a demo:**
- It does **not** ask "are you sure?" before writing a file or running a
  command (see the [safety note](#8-important-safety-note) below)
- It does **not** remember past sessions - closing the terminal clears
  the conversation
- It only talks to one AI provider (Anthropic's Claude) - not ChatGPT or others

## 3. Before you start

You'll need three things. None of them cost anything to set up except the
last one, which is pay-per-use (details below).

| # | What | Why |
|---|------|-----|
| 1 | A terminal | The text window you type commands into - "Terminal" on Mac, "PowerShell" or "Git Bash" on Windows, any terminal on Linux |
| 2 | `uv` (a Python project tool) | Installs the exact small set of libraries this project needs, in its own private folder, without touching anything else on your computer |
| 3 | An Anthropic API key | The password-like code that lets this program talk to Claude on your behalf |

You do **not** need to know Python to use this - you only need to type the
commands below exactly as written.

## 4. Setup, step by step

### Step 1 - Install `uv`

Open your terminal and run the command for your operating system:

**Mac or Linux:**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**Windows (PowerShell):**
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Close your terminal window and open a new one (so it picks up the change),
then check it worked:

```bash
uv --version
```

You should see something like `uv 0.11.28`. If instead your terminal
says it doesn't recognize `uv`, see [troubleshooting](#7-if-something-goes-wrong).

### Step 2 - Get the project code

```bash
git clone https://github.com/shrijayan/coding-agent.git
cd coding-agent
```

> This repository is **private**. If you're setting this up for someone
> else's demo, that person needs to be added as a collaborator on GitHub
> first, or you can hand them the folder directly instead of cloning.

### Step 3 - Install the project's dependencies

```bash
uv sync
```

This downloads the two small libraries the code needs (one to talk to
Claude, one to read the settings file you'll create in Step 6) into a
private folder called `.venv` inside the project. It does not install
anything globally on your computer.

### Step 4 - Get a Claude API key

1. Go to [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys)
   and sign up or log in.
2. If you haven't already, add a payment method under **Billing**. This
   is a separate thing from a claude.ai subscription - API usage is billed
   by how much you use it, not a flat monthly fee. Pricing is per "token"
   (roughly ¾ of a word): a few dollars per **million** tokens read and
   a bit more per million written - see
   [anthropic's pricing page](https://docs.claude.com/en/docs/about-claude/pricing)
   for current rates. A demo session with a handful of requests
   typically costs a few cents, well under a dollar.
3. Click **Create Key**, give it any name, and copy the key it shows you.
   It starts with `sk-ant-`. You won't be able to see it again after you
   navigate away, so copy it now.
4. Treat this key like a password - don't share it or post it publicly.

### Step 5 - Configure the project

Copy the example settings file to create your own:

```bash
cp .env.example .env
```

Open the new `.env` file in any text editor (TextEdit, Notepad, VS Code)
and paste your API key after the `=` sign on this line:

```
ANTHROPIC_API_KEY=sk-ant-your-key-goes-here
```

Leave every other line as it is for now - the defaults are fine for a
demo. (What each one does is explained in
[Settings you can tweak](#6-settings-you-can-tweak).)

### Step 6 - Run it

```bash
uv run coding-agent
```

You should see:

```
Coding Agent ready. Type 'exit' to quit.

you>
```

You're in. Type a request and press Enter.

## 5. Running your first demo

Try these in order - each one shows off a different capability, and
they're safe to run in a throwaway folder:

1. **Explore a project**
   `List all the files in this project`

2. **Create something**
   `Create a file called notes.txt with a 3-line poem about the ocean`

3. **Read and explain**
   `Read notes.txt and tell me what's in it`

4. **Edit precisely**
   `Add one more line to notes.txt about the moon`

5. **Write and run code**
   `Write a Python script that prints the first 10 Fibonacci numbers, then run it and show me the output`

To leave, type `exit` (or press Ctrl+C).

**Reading the screen while it works:**
- `you>` - a line you typed
- `  [tool] name({...})` - the agent telling you exactly what it's doing
  right now (which file, which command) before it does it
- `agent>` - its final answer to you, after it's done acting
- `error>` - something went wrong reaching Claude (see
  [troubleshooting](#7-if-something-goes-wrong)) - the session stays
  open, so you can just try again

## 6. Settings you can tweak

All settings live in your `.env` file (created in Step 5).

| Setting | What it controls | Default | When you'd change it |
|---|---|---|---|
| `ANTHROPIC_API_KEY` | Your secret key to talk to Claude | *(required, no default)* | Always required - the agent won't start without it |
| `AGENT_MODEL` | Which Claude model answers you | `claude-sonnet-5` | Rarely - only if you specifically want a different Claude model |
| `AGENT_MAX_TOKENS` | The longest answer Claude can give in one go | `4096` | Raise it if long answers seem to get cut off |
| `AGENT_MAX_ITERATIONS` | Max number of read/write/run steps allowed for one request, so it can't loop forever | `25` | Raise it for a task that genuinely needs many steps |
| `AGENT_BASH_TIMEOUT_SECONDS` | How long one terminal command is allowed to run before it's force-stopped | `60` | Raise it if you ask it to run something slow (e.g. a big test suite) |

## 7. If something goes wrong

| You see | It means | Fix |
|---|---|---|
| `Configuration error: Missing required environment variable 'X'` | Your `.env` file is missing, or you skipped a line | Re-run `cp .env.example .env` and make sure every line has a value |
| `command not found: uv` (or similar, wording differs by terminal) | `uv` isn't installed yet, or your terminal hasn't picked it up | Re-run the install command from Step 1, then fully close and reopen your terminal |
| `error> Claude API returned an error (401): invalid x-api-key` | Your API key is wrong, incomplete, or has no billing enabled | Fix `ANTHROPIC_API_KEY` in `.env`, confirm billing is set up at console.anthropic.com, then just try your request again - no need to restart |
| `error> Claude API returned an error (429): ...` | You've hit a rate limit (too many requests too quickly) | Wait a few seconds and try again |
| It pauses for a while, then errors about a timeout | A command took longer than `AGENT_BASH_TIMEOUT_SECONDS` | Raise that number in `.env` |
| `Stopped after N tool-use round-trips...` | The task needed more steps than `AGENT_MAX_ITERATIONS` allows | Raise that number in `.env`, or split your request into smaller asks |

Still stuck? Copy the exact error message - that's the fastest way for
anyone helping you to diagnose it.

Any line starting with `error>` means something went wrong talking to
Claude (bad key, no internet, rate limit, Anthropic's servers being
temporarily down, ...) - it's shown as a clean one-line message and the
session stays open, so you can just fix the cause and try again without
restarting.

## 8. Important safety note

This agent **can create, overwrite, and delete real files, and run any
terminal command**, in whatever folder you launch it from - without
pausing to ask "are you sure?" first (that confirmation step doesn't
exist yet in this version).

Before a demo:
- Run it inside a project that's saved with `git`, or a throwaway test
  folder, so you can always undo changes (`git checkout .`) if needed.
- Don't point it at anything you can't afford to lose or break.
- Don't ask it to run a command you wouldn't be comfortable running yourself.
